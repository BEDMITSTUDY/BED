# BED v3 — MIT Campus Micro-Pilot Specification (Synthetic)

This document outlines the structure of the synthetic MIT micro-pilot used for
public demonstration and analysis.

## 1. Pilot Nodes (Synthetic)

The pilot includes five synthetic MIT campus nodes:

- MIT-C1: Stratton Student Center
- MIT-C2: Stata Center
- MIT-L1: Barker Library
- MIT-G1: Zesiger Gym
- MIT-S1: Sloan E62

These identifiers are synthetic and do not represent real deployment data.

## 2. Pilot Objectives

- Demonstrate closed-loop behavioral incentive delivery
- Validate CMDP policy behavior under synthetic constraints
- Evaluate habit, recency, and responsiveness dynamics
- Provide reproducible academic results

## 3. Pilot Flow

1. User interacts with a location (synthetic event)
2. Hazard model computes event probability
3. CMDP policy decides whether to send an incentive
4. Behavioral state updates
5. Data logged for analysis

## 4. Safety and Ethics

This pilot is entirely synthetic and does not involve real users, real data, or
real incentives. It is designed solely for academic demonstration.
