# Contributing to BED v3

Thank you for your interest in contributing to the Behavioral Engine for Demand
(BED) v3 project.

## Guidelines

- All contributions must use synthetic data only.
- Do not submit real-world logs, partner integrations, or production code.
- Follow the repository structure and documentation conventions.
- Use clear commit messages and descriptive pull requests.

## Academic Contributions

If you are contributing research ideas, please reference relevant literature and
include reproducible examples when possible.

## Code Style

- Python: PEP8
- JavaScript: StandardJS
- LaTeX: MIT thesis conventions

## Contact

For major contributions or collaborations, please contact the project author.
