# Behavioral Engine for Demand (BED) v3
### MIT Campus Micro‑Pilot, Simulation Framework, and Prototype Architecture

This repository contains the public, academic-facing implementation of the
Behavioral Engine for Demand (BED) v3, including:

- Agent‑based behavioral simulation
- Constrained Markov Decision Process (CMDP) policy engine
- Synthetic MIT campus micro‑pilot dataset
- Minimal working prototype (QR → Web → Cloud Function → Firestore)
- Analysis notebooks and reproducible workflows
- Full LaTeX thesis source (MIT‑style)

This repository is designed for transparency, reproducibility, and academic
collaboration. All sensitive, proprietary, or production‑grade components are
intentionally excluded (see NOTICE).

---

## Repository Structure
simulation/   - Behavioral engine, hazard model, CMDP solver, simulation runner
prototype/    - Cloud function backend, static web page, QR generator
data/         - Synthetic MIT micro‑pilot dataset + schema
analysis/     - Jupyter notebooks, figures, tables
docs/         - Architecture diagrams, pilot specification, research agenda
thesis/       - Full LaTeX source for the BED v3 research manuscript
