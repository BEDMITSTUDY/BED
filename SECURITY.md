# Security Policy

This repository is intended for academic research and educational use only.

## Reporting Misuse
If you observe misuse of this repository, including attempts to deploy BED in
commercial environments without permission, please contact the author.

## Scope
This repository does NOT include:
- Production-grade incentive delivery systems
- Real user data
- Authentication or identity systems
- Deployment pipelines

Any attempt to use this code in production without proper safeguards is strongly
discouraged.
