\chapter{Experiment Protocols}

\section{Randomization}

Users are randomly assigned to:
control, heuristic, or BED policy groups.

\section{Outcome Measurement}

Primary outcomes:
\begin{itemize}
    \item engagement rate,
    \item habit trajectory,
    \item budget utilization.
\end{itemize}

Secondary outcomes:
\begin{itemize}
    \item responsiveness stratification,
    \item fairness metrics.
\end{itemize}

\section{Analysis Methods}

\begin{itemize}
    \item difference-in-means,
    \item survival analysis,
    \item ANOVA,
    \item bootstrap confidence intervals.
\end{itemize}
