\chapter{Experiment Design}

This chapter presents the experimental design used to evaluate the Behavioral
Engine for Demand (BED) across simulation and prototype environments. The goal
is to assess how different incentive policies influence behavioral trajectories,
budget utilization, and long-term engagement. The experiment design integrates
synthetic simulations, controlled treatment assignment, and structured event
logging to ensure reproducibility and statistical rigor.

\section{Objectives}

The experiments are designed to answer four core questions:

\begin{enumerate}
    \item \textbf{Effectiveness}: Do BED policies increase engagement relative
    to baseline or heuristic policies?
    \item \textbf{Efficiency}: How many incentives are required to achieve a
    given level of engagement?
    \item \textbf{Behavioral Impact}: How do incentives influence habit
    formation and responsiveness over time?
    \item \textbf{Budget Performance}: How well does the CMDP respect budget
    constraints while maximizing long-term outcomes?
\end{enumerate}

These objectives guide the structure of both simulation-based and prototype
experiments.

\section{Experimental Conditions}

Experiments are conducted under multiple conditions to evaluate robustness:

\begin{itemize}
    \item \textbf{Responsiveness Levels}: low, medium, and high responsiveness
    segments.
    \item \textbf{Budget Levels}: low-budget, medium-budget, and high-budget
    regimes.
    \item \textbf{Policy Types}: BED CMDP policy, heuristic policies, and
    no-incentive baseline.
    \item \textbf{Time Horizons}: short (50 steps), medium (200 steps), and
    long (500+ steps).
\end{itemize}

These conditions allow for factorial comparisons across behavioral and
operational dimensions.

\section{Treatment Groups}

The experiment uses a multi-arm structure:

\begin{itemize}
    \item \textbf{Control Group}: no incentives delivered.
    \item \textbf{Heuristic Group}: incentives delivered based on simple rules
    (e.g., recency threshold).
    \item \textbf{BED Policy Group}: incentives delivered using the CMDP policy.
\end{itemize}

This structure enables causal inference regarding the impact of BED policies.

\section{Simulation Workflow}

The simulation experiment follows a structured workflow:

\begin{enumerate}
    \item \textbf{Initialize Population}: generate synthetic users with
    heterogeneous responsiveness.
    \item \textbf{Assign Treatment Group}: each user is assigned to control,
    heuristic, or BED policy.
    \item \textbf{Run Simulation}: execute the simulation for a fixed number of
    steps.
    \item \textbf{Log Trajectories}: record state, action, event, and budget
    usage at each step.
    \item \textbf{Compute Metrics}: evaluate engagement, habit formation,
    incentive efficiency, and budget utilization.
\end{enumerate}

This workflow mirrors the structure of the simulation environment described in
Chapter 6.

\section{Prototype Experiment Workflow}

The prototype experiment uses real QR scans to generate synthetic events. The
workflow is:

\begin{enumerate}
    \item \textbf{QR Scan}: user scans a QR code.
    \item \textbf{Backend Trigger}: the serverless backend assigns a treatment.
    \item \textbf{Event Logging}: the event is written to Firestore.
    \item \textbf{Offline Analysis}: logs are exported and analyzed using the
    same metrics as the simulation.
\end{enumerate}

Although simplified, this workflow demonstrates how BED can be deployed in
real-world environments.

\section{Metrics}

The following metrics are used to evaluate policy performance:

\subsection{Engagement Metrics}

\begin{itemize}
    \item \textbf{Engagement Rate}: proportion of time steps with events.
    \item \textbf{Time-to-Event}: average number of steps between events.
\end{itemize}

\subsection{Behavioral Metrics}

\begin{itemize}
    \item \textbf{Habit Trajectory}: evolution of $h_t$ over time.
    \item \textbf{Recency Distribution}: distribution of $r_t$ across users.
\end{itemize}

\subsection{Policy Metrics}

\begin{itemize}
    \item \textbf{Incentive Efficiency}: events per incentive delivered.
    \item \textbf{Budget Utilization}: fraction of budget spent.
    \item \textbf{Fairness Index}: variance in incentive exposure across
    segments.
\end{itemize}

\section{Statistical Methods}

To ensure rigorous evaluation, the following methods are used:

\begin{itemize}
    \item \textbf{Difference-in-Means}: compare engagement rates across groups.
    \item \textbf{Survival Analysis}: evaluate time-to-event distributions.
    \item \textbf{ANOVA}: test differences across multiple treatment arms.
    \item \textbf{Bootstrap Confidence Intervals}: quantify uncertainty in
    estimates.
\end{itemize}

These methods support robust inference even under stochastic behavioral
dynamics.

\section{Parameter Sweeps}

To explore sensitivity, experiments include parameter sweeps over:

\begin{itemize}
    \item habit retention $\alpha$,
    \item reinforcement increment $\gamma$,
    \item incentive decay rate $\lambda$,
    \item hazard model coefficients,
    \item CMDP budget $B$.
\end{itemize}

Parameter sweeps reveal how BED performance varies across behavioral and
operational regimes.

\section{Reproducibility}

All experiments are reproducible due to:

\begin{itemize}
    \item fixed random seeds,
    \item configuration files stored in YAML,
    \item deterministic state update rules,
    \item logged trajectories for all runs.
\end{itemize}

This ensures that results can be replicated and audited.

\section{Summary}

This chapter described the experimental design used to evaluate BED policies in
